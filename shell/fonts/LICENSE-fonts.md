# Fonts

`Nyaspace-Variable.ttf` is a modified version of **Monaspace Neon** (variable) by GitHub Next,
extended with Nerd Fonts icon glyphs and extra Unicode coverage.

* Monaspace is licensed under the **SIL Open Font License 1.1** — full text in `OFL.txt`.
  "Monaspace" (and its subfamily names) are Reserved Font Names, so the modified font
  is distributed under a different family name: **Nyaspace**.
* Nerd Fonts glyphs: https://github.com/ryanoasis/nerd-fonts/blob/master/LICENSE
  (the Font Awesome icons inside are under OFL 1.1 as well).

Nyaspace is distributed under the same SIL Open Font License 1.1.
